# Industrial Surface Defect Detection

This project is being prepared for the Image Processing course at Okan University.

**Student:** Selin Korkmaz  
**Student ID:** 220218041  
**Department:** Software Engineering

## About the Project

The aim of this project is to detect defects such as scratches and cracks on industrial product surfaces using image processing techniques.

I plan to develop a simple application that analyzes product images, detects possible defects, and highlights them on the image.

## How It Will Work

The project will include the following steps:

1. Upload an image of a product.
2. Convert the image to grayscale and reduce noise.
3. Use image processing methods to detect defects.
4. Highlight the detected defects on the original image.
5. Display the results.

## Technologies

I plan to use:

- Python
- OpenCV
- NumPy
- Streamlit

## Dataset

I plan to use images from the MVTec AD dataset to test the application.

Dataset: https://www.mvtec.com/company/research/datasets/mvtec-ad

## Expected Result

At the end of the project, I aim to create an application that can detect possible surface defects and show their locations on product images.

I also plan to compare different image processing methods to see which ones give better results.
